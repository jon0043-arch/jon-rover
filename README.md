# Jon Rover

Personal Jaguar Land Rover sales website for Jon McGeehan.

## Stack

- Next.js
- React
- TypeScript
- GSAP / ScrollTrigger
- Vercel
- Supabase later

## Current build

The initial homepage structure is in place with:

- responsive hero
- layered/parallax hero scroll motion
- model lineup section
- personal approach section
- final vehicle-finder CTA

## Required asset

Add the approved hero image to:

`public/hero-defender.png`

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
